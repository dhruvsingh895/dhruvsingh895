## Engineering philosophy

- Make the main workflow obvious before adding more features.
- Keep boundaries clear between UI, APIs, data, and background processing.
- Prefer measurable behavior over impressive-sounding claims.
- Treat loading, error, empty, and recovery states as part of the product.
- Build for maintainability: small responsibilities, explicit interfaces, and documentation that matches the implementation.
